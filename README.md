
# CyberShield – Phishing Detection System

## About the Project
CyberShield is a student cybersecurity project that analyzes website URLs for potentially suspicious characteristics.

It uses Python, Flask, and a machine learning model to provide a demonstration of URL phishing detection.

## Features
- URL input and analysis
- Machine learning-based prediction
- Basic suspicious URL indicators
- Simple web interface
- Security awareness warning

## Technologies Used
- Python
- Flask
- Pandas
- Scikit-learn
- Joblib
- HTML
- CSS

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install the required packages:

   pip install -r requirements.txt

4. Train the demonstration model:

   python train_model.py

5. Start the Flask application:

   python app.py

6. Open this address in your browser:

   http://127.0.0.1:5000

## Disclaimer
This project is an educational prototype using a small demonstration dataset. Its predictions are not reliable proof that a URL is safe or malicious. Do not use it as the only method of detecting phishing websites.
